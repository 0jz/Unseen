01 — Overview
What UNSEEN is.
A multi-agent adversarial AI system that attacks your strategy document before an investor does.

UNSEEN takes any strategy document — pitch deck, board memo, pivot plan, fundraising narrative — and runs six specialized AI agents against it simultaneously. Each agent has a distinct adversarial role: mapping logic, steelmanning, attacking, detecting organizational blindness, generating the questions nobody asks, and synthesizing everything into a client-ready briefing.

The result is a complete adversarial review in 60–90 seconds, formatted as an advisory brief that a strategic consultant can hand directly to a client. What McKinsey charges $250,000–$2,000,000 to produce, UNSEEN produces in minutes.

UNSEEN is not a chatbot. It is not a document summarizer. It is not a pitch coach. It is an adversarial intelligence system: it is designed to find what is wrong, what is invisible, and what will be challenged — before the investor finds it first.

Core repositioning (UNSEEN 3.0): Primary customer is no longer the strategic advisor alone — it is the startup founder preparing for fundraising. The tool is repositioned from "prediction" (what will the investor ask?) to "preparation" (how do I think like an investor before I walk in?). This distinction matters: preparation is always valuable, always correct. Prediction can fail and destroy trust.

02 — Agent architecture
The six agents.
Six agents. Six adversarial lenses. One briefing that no single consultant could produce alone.
01
Logic Mapper
Structural Analysis · Returns JSON
Maps the underlying reasoning structure of the document. Extracts the core claim, explicit and implicit assumptions, critical dependencies (if X then Y), and structural weaknesses. Output is structured JSON used by every subsequent agent as shared context. This is the foundation on which all other analysis is built.
02
Bull Advocate
Steelman Analysis · Prose Output
Makes the strongest possible case for the strategy. Finds every market tailwind, every underappreciated strength, every reason the timing is right. Uses real benchmarks (NRR targets, ARR medians, sector growth rates) to ground the optimism in data. 4–5 paragraphs of genuinely persuasive prose. The goal is not cheerleading — it is to identify what is actually good so the founder can defend it.
03
Bear Advocate
Adversarial Attack · Prose Output
Finds every failure mode — the hidden risks, broken assumptions, execution traps, and market dynamics that will destroy the strategy. Uses CB Insights failure pattern data, sector-specific risk libraries (AI commoditization, fintech regulatory risk, marketplace chicken-and-egg problems), and YC-era funding realities. Does not hedge. Names the failure with precision.
04
Blind Spot Detector
Organizational Psychology · Prose Output
Identifies the assumption the organization cannot see — not because it is hidden, but because it is socially protected from scrutiny. Uses organizational psychology frameworks: groupthink, HiPPO effect (highest-paid person's opinion), motivated reasoning, confirmation bias, illusion of control. Three-part structure: THE BLIND SPOT (1 sentence) → WHY THEY CANNOT SEE IT (2–3 sentences) → WHAT WOULD CHANGE (2–3 sentences). The most uncomfortable and most valuable output of the system.
05
Question Generator
Socratic Analysis · Returns JSON
Generates five questions that nobody in the room is asking — specific, uncomfortable, and demanding real answers. Uses a Socratic taxonomy: assumption questions, alternative questions, implication questions, evidence questions, perspective questions, timing questions, and reversal questions. Each question includes: the question itself, why it is being avoided, and what changes if the answer is uncomfortable.
06
Insight Synthesizer
Executive Briefing · Prose Output
Synthesizes all five prior agent outputs into a 3-paragraph executive briefing that an advisor can hand directly to a client. Paragraph 1: what the strategy is trying to accomplish and why it matters. Paragraph 2: the single most important finding from the adversarial review. Paragraph 3: the recommended next action. Written in the voice of the smartest person in the room. No hedging, no ambiguity.

Agents run sequentially — each agent receives the outputs of prior agents as context. Logic Mapper → Bull → Bear → Blind Spot → Questions → Synthesizer. The Synthesizer sees everything. Total analysis time: 60–120 seconds.

03 — Intelligence layer
The knowledge base.
Each agent is injected with a structured knowledge block that makes it a domain expert, not a generalist.

Without a knowledge base, every LLM call produces generic output. With it, the Bear Advocate knows that B2B SaaS enterprise sales cycles take 6–18 months (not 3), that AI products face commoditization risk from OpenAI, that fintech companies consistently underestimate regulatory timelines. This is the difference between an advisor who has read 1,000 post-mortems and one who just started.

04 — Technical architecture
How it's built.
Deliberately minimal stack. No database, no build step, no auth. Built to ship and demo, not to over-engineer.
LayerTechnologyWhy
BackendNode.js + ExpressFast to write, easy to demo, no compilation
AIclaude-sonnet-4 via @anthropic-ai/sdkBest reasoning quality for adversarial analysis tasks
File parsingMammoth (DOCX) + pdf-parse (PDF)Handles all common document formats without external services
FrontendVanilla JS + HTML — no build stepInstant refresh, no toolchain, works on any machine
FontsCormorant Garamond + Courier PrimeEditorial luxury feel — weight 300 base, italic for emphasis
Job systemIn-memory Map + polling every 1.5sAsync analysis without blocking HTTP response
StorageNone — jobs auto-clear after 24hNo GDPR surface, no database to maintain
ExportServer-rendered HTML → browser printPDF export without libraries — native browser quality

Document context strategy: Each agent receives a different window into the document — Logic Mapper sees 8,000 chars (beginning + end), Bull/Bear see 6,000, Blind Spot sees 7,000, Questions see 5,000. The prepareDoc() function always includes beginning and end of document (65%/35% split) so agents never only see the introduction of a long document.

Cost per analysis: Approximately $0.15–$0.35 per full 6-agent analysis on claude-sonnet-4 ($3/MTok input, $15/MTok output). Logged to console after every run. At $49/report pricing, gross margin is 99%+ on API costs.

07 — Risk management
Three risks, neutralized.
Each risk, properly addressed, becomes a competitive advantage that is difficult to replicate.
R1
Market Periodicity — founders raise once every 12–24 months
Neutralized
The problem: 39% of companies take 3+ years to go from seed to Series A — double the rate of three years ago. The average founder is actively fundraising only 3–4 months per year. A monthly subscription to a "fundraising tool" fails if the user doesn't use it for 8 months.
Solution
Four recurring use cases (above) transform UNSEEN from a pitch tool into a permanent strategic partner. Per-session pricing removes the friction of paying for months of non-use. One founder = 6–10 sessions/year. What becomes the competitive advantage: "Not a pitch tool — a permanent strategic partner for founders."
R2
No investor-specific knowledge base — generic output is replaceable
In Progress
The problem: "What would Sequoia ask?" is fundamentally different from "What would YC ask?" Without investor-specific profiles, UNSEEN is replaceable by Claude directly. This is the only thing that builds a long-term moat.
Three-phase solution
Phase 1 (Months 0–3, now): Public data. YC: paulgraham.com essays, partner blogs, Startup School videos, Michael Seibel interviews. Sequoia: pitch deck template, Doug Leone interviews, Arc requirements. a16z: pmarca essays, investment theses, partner podcast transcripts.

Phase 2 (Months 3–6): Crowdsourced intelligence. After each pitch meeting, UNSEEN asks: "What questions did they ask?" Founder inputs 3–5 real questions (incentivized with $20 discount). UNSEEN calibrates investor profile. Each new founder targeting that investor gets a better result.

Phase 3 (Months 6–12): Verified data moat. "Sequoia asks about X in 80% of cases." "This YC question kills 40% of applications." Pattern differences between DA and NE investors by vertical. What becomes the competitive advantage: "Self-improving system that gets better with every user."
R3
Founder confidence — one wrong prediction destroys trust
Neutralized
The problem: If a founder receives UNSEEN's analysis, trusts it, walks into the pitch, and the investor asks something completely different — the founder loses confidence, leaves, and tells others. The founder community is small and connected. Negative reputation spreads exponentially.
Key reframe: Prediction → Preparation
Wrong: "UNSEEN predicts what the investor will ask." (Promise. Can be wrong. Destroys trust.)
Right: "UNSEEN prepares you to think like an investor before you walk in." (Service. Always valuable. Always correct.)

Four trust mechanisms: (1) Calibration Score — founder rates match after each pitch, UNSEEN shows average accuracy per investor profile. Transparency builds more trust than claims of perfection. (2) Pre/Post Case Studies — "Founder X uploaded deck. UNSEEN flagged blind spot. Investor asked exactly that. Round closed." (3) Practice Mode / Freemium — 3 of 6 agents free. See value before paying. (4) Human Review tier — AI analysis + 30-min advisor call. Founder walks in with two layers of confidence. What becomes the competitive advantage: "The only tool honest about accuracy — and therefore trusted."

11 — Design philosophy
Six principles.
The interface communicates the product's intelligence before the user reads a word.
#PrincipleWhat it means in practice
01 Quiet authority Does not announce itself. Commands attention by removing everything that competes for it. No gradients, no hero illustrations, no celebration animations.
02 Earned luxury Premium is not expensive. Premium is the absence of anything cheap. Cormorant Garamond weight 300. Courier Prime at 7pt letter-spacing 0.2em. Gold that doesn't shout.
03 Trust through clarity Trustworthy interfaces do not look reliable — they are reliable, and the design makes that visible. Every agent shows its status. Every cost is logged. Nothing is hidden.
04 Action over decoration Every element either helps the user do something or it is removed. The decorative circles in the hero are the only non-functional element — and they cost nothing.
05 Refined restraint Refinement is knowing what to take away. The progress bar is 1px. The agent dots are 6px. The gold is #c9a84c, not yellow.
06 Sensory precision Timing, weight, spacing communicate before content does. The breathe animation on active agents is 3 seconds — slower than you think it needs to be. If it feels wrong, wait. If it still feels wrong, remove it.
